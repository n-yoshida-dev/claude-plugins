画面の見本 1 枚と、狙いの説明 1 つ。

1. `index.html`：見本の HTML 1 枚。CSS と JavaScript はファイルの中に書く（外のファイル・外のサイトの画像やフォントを読まない。比較ページの枠の中で、ネットにつながずに表示するため）。
   画像が要る所は、色の付いた四角や文字で場所だけ示す。横幅 1280px と 375px（スマホ）のどちらでも、横にはみ出さない
2. `aim.md`：狙い。次の 3 つの見出しで書く
   - `## 狙い`：この見本で何を良くしたか、3 行
   - `## 節ごとの工夫`：ブリーフの「節」ごとに 1〜2 行
   - `## 文面を変えた所`：材料の正本の文から変えた所を「元の文 → 変えた文」で 1 行ずつ。変えていなければ「なし」
